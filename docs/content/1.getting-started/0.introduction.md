## What version skew means

:SkewProtectionDemoAuto

A deployment replaces several things at once: HTML, JavaScript, CSS, payloads, and server behavior. Browsers do not switch atomically. An open tab can keep release A running while the server and asset origin already serve release B.

That creates two separate failure classes:

1. The old client requests an asset from release A that release B no longer serves. Lazy route imports are the common example.
2. The old client sends a request shaped for release A to a release B server endpoint.

Portable mode handles the first class. It stores immutable Nuxt build assets by full path, restores retained files into the next output, and rejects a build if the same supposedly immutable URL contains different bytes.

For the second class, this module can detect a deployment and ask the browser to reload. It cannot serve an old API or SSR endpoint after that endpoint has gone away. Keep server changes compatible during the reload window, or use deployment affinity from your hosting platform.

## Update detection

Nuxt owns the deployment manifest and emits `app:manifest:update`. The module uses that hook as the one update event. You can learn about a deployment through:

- Nuxt manifest polling
- SSE on a persistent Node server
- [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket) on Cloudflare Durable Objects
- Pusher or Ably

The transport changes latency. It does not change which session is safe. A loaded JavaScript module has already executed; the risky asset is usually a lazy module the old client has not requested yet. The module therefore prompts on a deployment update instead of claiming loaded-chunk precision.

## Retention boundary

`retentionDays` and `maxNumberOfVersions` bound which old asset URLs remain available. Cleanup runs before old files are restored and before release metadata is written, so clients only see versions the build shipped.

Native platform affinity is a different model. The provider routes a client back to its complete old deployment, including server behavior when supported. Portable asset retention and native affinity should not be treated as equivalent.

[Install the module](/docs/skew-protection/getting-started/installation) when that boundary fits your rollout model.
