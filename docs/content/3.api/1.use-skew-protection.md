`useSkewProtection()`{lang="ts"} returns one shared update engine per Nuxt app. Calling it from several components does not create more connections, queues, or hook listeners.

```ts
const skew = useSkewProtection()
```

The connection starts when Nuxt is ready. Use `connect()`{lang="ts"} and `disconnect()`{lang="ts"} when you need explicit control.

## State

### `manifest`{lang="ts"}

`Ref<NuxtAppManifestMeta | undefined>`{lang="html"} containing the newer manifest after Nuxt emits `app:manifest:update`.

### `clientVersion`{lang="ts"}

The build ID of the JavaScript currently running in this tab.

### `serverVersion`{lang="ts"}

`ComputedRef<string | undefined>`{lang="html"} containing the latest version reported by SSE, [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket), or an adapter connection.

### `isAppOutdated`{lang="ts"}

`ComputedRef<boolean>`{lang="html"} that becomes true when `manifest.id` differs from `clientVersion`.

### `isRollback`{lang="ts"}

`ComputedRef<boolean>`{lang="html"} derived from retained release timestamps. It becomes true when the reported server release predates the client release.

### `isConnected`{lang="ts"}

`ComputedRef<boolean>`{lang="html"} describing the module connection. Polling does not create an SSE or WebSocket connection.

### `isOnline`{lang="ts"}

The reactive online state from [VueUse](https://vueuse.org).

## Methods

### `connect()`{lang="ts"} and `disconnect()`{lang="ts"}

Open or close the configured update connection. The methods are idempotent.

### `checkForUpdates()`{lang="ts"}

Fetch the latest Nuxt app manifest once. Failed or incomplete deployment reads remain retryable.

```ts
const { checkForUpdates } = useSkewProtection()
await checkForUpdates()
```

### `onAppOutdated()`{lang="ts"}

Register a callback on Nuxt's `app:manifest:update` hook. Vue removes the listener with the current scope when one exists.

```ts
const { onAppOutdated } = useSkewProtection()

onAppOutdated((manifest) => {
  console.log('Deployment available', manifest?.id)
})
```

### `simulateUpdate()`{lang="ts"}

Emit a fake manifest update in development. Production calls do nothing.

## Nuxt manifest shape

The module adds retention timestamps to Nuxt's manifest metadata:

```ts
interface NuxtAppManifestMeta {
  id: string
  timestamp: number
  skewProtection?: {
    versions?: Record<string, {
      timestamp: string
      expires: string
    }>
  }
}
```

Asset lists stay in build storage. They are not sent to every browser.
