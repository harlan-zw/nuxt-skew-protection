`<SkewNotification>`{lang="html"} wraps the shared `useSkewProtection()`{lang="ts"} engine and supplies display state through its default slot.

```vue
<template>
  <SkewNotification v-slot="{ isAppOutdated, dismiss, reload, timeAgo }">
    <div v-if="isAppOutdated" class="notification">
      <p>New deployment available, {{ timeAgo }}</p>
      <button @click="reload">
        Reload
      </button>
      <button @click="dismiss">
        Not now
      </button>
    </div>
  </SkewNotification>
</template>
```

## Slot props

### `version`{lang="ts"}

The build ID of the client code running in this tab.

### `isAppOutdated` and `isOpen`{lang="ts"}

Both are booleans. They become true after a deployment manifest update, unless the user dismissed the current notification. A later manifest ID resets dismissal.

### `dismiss()`{lang="ts"}

Hide the notification for the current deployment update and emit `dismiss`.

### `reload()`{lang="ts"}

Emit `reload`, then call `reloadNuxtApp({ force: true })`{lang="ts"}. Nuxt state is not persisted across releases.

### `timeAgo`{lang="ts"}

A reactive, human readable age from [VueUse](https://vueuse.org), such as `2 minutes ago`.

### `releaseDate`{lang="ts"}

A `Date` built from the newer manifest timestamp.

### `isPrerendered`{lang="ts"}

Whether Nuxt marked the current payload as prerendered. Deployment updates still show on prerendered pages because those clients can request lazy assets and current server endpoints.

## Props

`forceOpen`{lang="ts"} forces the slot open in development previews and component tests.

```vue
<SkewNotification v-slot="{ isOpen, reload }" force-open>
  <button v-if="isOpen" @click="reload">
    Preview update
  </button>
</SkewNotification>
```

## Events

- `dismiss`
- `reload`
- `update:open`, with the current boolean state
