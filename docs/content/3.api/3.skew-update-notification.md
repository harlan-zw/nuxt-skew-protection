A ready-made Vue component for update notifications.

The default `prompt` strategy stays headless until this component mounts.

## Usage

Add the component once in `app.vue` or a layout:

```vue [app.vue]
<template>
  <NuxtPage />
  <SkewUpdateNotification />
</template>
```

The component appears when it detects an update.
Refresh loads the new version. Dismiss hides the current notification.

Use [`<SkewNotification>`{lang="html"}](/docs/skew-protection/api/skew-notification) when you need custom content or styles.
